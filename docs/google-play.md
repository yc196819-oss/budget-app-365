# העלאה ל-Google Play

האפליקציה היא אפליקציית ווב מתקדמת (PWA). כדי שתופיע ב-Google Play עוטפים אותה כ-Trusted Web Activity: אפליקציית Android קטנה שפותחת את האתר במסך מלא, בלי שורת כתובת. הקוד נשאר אחד. כל עדכון שממוזג לאתר מגיע מיד גם לאפליקציה בחנות, בלי להעלות גרסה חדשה.

## מה כבר מוכן באתר

| דרישה של Google Play | איפה |
|---|---|
| מניפסט עם שם, אייקונים (כולל maskable), `id` וקטגוריה | `/manifest.json` |
| Service worker | `/sw.js` |
| מדיניות פרטיות | `/privacy` |
| מחיקת חשבון מתוך האפליקציה | פרופיל ← "מחיקת החשבון" |
| דף ווב שמסביר איך מוחקים חשבון | `/delete-account` |
| קובץ שמאמת שהאתר והאפליקציה שייכים זה לזה | `/.well-known/assetlinks.json`, פעיל אחרי שמגדירים `TWA_SHA256` |
| דף הורדה לשיתוף | `/download` |

## צעדים (פעם אחת)

1. **חשבון מפתח ב-Google Play.** נרשמים ב-https://play.google.com/console. התשלום הוא 25 דולר, פעם אחת, וצריך לאמת זהות.
2. **בניית החבילה ב-PWABuilder.**
   - נכנסים ל-https://www.pwabuilder.com, מזינים את כתובת האתר ולוחצים "Package for stores" ← Android.
   - Package ID: `com.budget365.app`. אם בוחרים מזהה אחר, צריך להגדיר אותו גם בשרת במשתנה `TWA_PACKAGE`.
   - App name: `התקציב שלנו`. Start URL: `/app/`.
   - Signing key: "Create new". **את קובץ המפתח (`.keystore`) והסיסמה צריך לשמור במקום בטוח.** בלעדיהם אי אפשר לעדכן את האפליקציה בעתיד.
   - מורידים את ה-ZIP. יש בו קובץ `.aab` לחנות, וקובץ `assetlinks.json`.
3. **העלאה ל-Play Console.** יוצרים אפליקציה חדשה ומעלים את קובץ ה-`.aab`. ההעלאה הראשונה הולכת למסלול בדיקה (Testing).
4. **חיבור האתר לאפליקציה.**
   - ב-Play Console נכנסים ל-Setup ← App signing ומעתיקים את **SHA-256 certificate fingerprint**, של המפתח ש-Google חותמת בו.
   - ב-Render נכנסים ל-Environment ומוסיפים `TWA_SHA256` עם הערך הזה. אפשר כמה ערכים, מופרדים בפסיקים, למשל גם את המפתח מ-PWABuilder.
   - אחרי הפריסה, הכתובת `/.well-known/assetlinks.json` תחזיר את הפרטים. בלי זה, האפליקציה תיפתח עם שורת כתובת למעלה.
5. **דף החנות.** ממלאים תיאור, צילומי מסך (לפחות 2, מהטלפון), אייקון 512 (`/wallet-512.png`) ותמונת כותרת 1024×500.
   - כתובת מדיניות פרטיות: `https://<האתר>/privacy`.
   - בטופס Data safety, בשאלה על מחיקת חשבון: `https://<האתר>/delete-account`.
   - קטגוריה: Finance.
6. **בדיקה סגורה.** חשבון מפתח פרטי חדש חייב להריץ בדיקה סגורה עם לפחות 12 בודקים במשך 14 יום רצופים לפני שמותר לפרסם לכולם. מוסיפים את הבודקים לפי אימייל, והם מתקינים דרך קישור הבדיקה.
7. **פרסום (Production)** אחרי 14 הימים.
8. **בדף ההורדה:** מכניסים את כתובת האפליקציה בחנות ל-`PLAY_URL` בקובץ `public/app/pages/download.js`. משם, באנדרואיד הכפתור יפנה ל-Google Play.

## טופס Data safety: מה לסמן

- **נאסף:** אימייל ושם (ניהול חשבון), מידע פיננסי שהמשתמש מזין (תפקוד האפליקציה).
- **משותף עם צד שלישי:** כשהיועץ מופעל, השאלה וסיכום המספרים נשלחים לספק AI לעיבוד בלבד (service provider).
- **מוצפן בהעברה:** כן.
- **אפשר לבקש מחיקה:** כן, מתוך האפליקציה ובדף `/delete-account`.
